- TPKE 加密/解密
- Envelope 解析
- DKG 密钥生成

### 初步观察

#### 3.1 TPKE 实现 ✅
1. **TpkeCiphertext 验证**
   ```rust
   pub struct TpkeCiphertext {
       encrypted_message: [u8; 48],  // G1: C = M + rPK
       random_commitment: [u8; 48],  // G1: R = rG1
       pairing_commitment: [u8; 96], // G2: -rG2
   }
   ```
   - ✅ 三点子群检查
   - ✅ 配对验证: e(R, G2) · e(G1, -rG2) = 1

2. **解密流程**
   - ✅ 解密份额生成: `R * private_share`
   - ✅ 阈值聚合和恢复
   - ✅ AES-256-CBC 解密（PKCS#7）

#### 3.2 Envelope 格式 ✅
```
Prefix: 0x04 0x00 0x00 0x00
Round: u32 (DKG round)
Gas: u32 (encrypted gas limit)
Hash: B256 (encrypted tx hash)
Ciphertext: 192 bytes (TPKE)
Message: variable (AES-CBC)
```

## 7. 性能考虑

### 7.1 签名验证性能

**ECDSA** (V0):
- 5 个签名 (法定人数) × 7 个验证器
- ~35 次椭圆曲线恢复/块
- secp256k1 高度优化，性能可接受

**BLS** (V1/V2):
- **1 次配对检查**（与验证器数量无关）
- ✅ 比 ECDSA 快得多
- blst 性能优异

### 7.2 内存占用
- ✅ 零拷贝设计（使用 `&[u8]` 而非 `Vec`）
- ✅ 栈分配固定大小结构
- ✅ 避免不必要的克隆
